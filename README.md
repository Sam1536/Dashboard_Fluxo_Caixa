# 💵 Dashboard de Fluxo de Caixa | Power BI

Dashboard interativo para acompanhar o fluxo de caixa: **saldo inicial**, **entradas**, **saídas**, **saldo final** e **margem**, com evolução mês a mês e análise das despesas por classificação e centro de custos.

## ✨ Recursos

- Indicadores de **Saldo Inicial**, **Entradas**, **Saídas**, **Saldo Final** e **Saldo**
- Medidor de **margem**
- Gráfico de cascata com a evolução do saldo mês a mês
- Saídas por classificação
- Filtros por período e por centro de custos
- Tooltip personalizado com o detalhamento das despesas

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
